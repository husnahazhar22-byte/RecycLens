# RecycLens UI/UX Design

This folder contains the UI/UX design materials for the RecycLens project.

## Design Overview

RecycLens is designed to provide a simple and accessible recycling experience through an image-based recognition workflow.

## Design Goals

- Create a clean and user-friendly interface.
- Make recyclable item identification easy to access.
- Help users discover nearby recycling centres.
- Connect users with recycling collectors offering home collection services.
- Provide a responsive experience across desktop and mobile devices.
